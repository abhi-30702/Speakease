**Version:** 1.0  
**Date:** 2026-07-31  
**Author:** Abhishek K

## Goal

Replace the regex cleanup tier with Groq API inference, log every dictation to a local SQLite database, and build a full Insights dashboard in MainWindow — matching the Wispr Flow dashboard design from PRD section 8.2.

**M2 exit criteria:**
- ≥ 80% of dictations need no manual edit (Groq cleanup handles fillers, self-corrections, punctuation, capitalisation)
- All dictation data persists locally in SQLite (app name, WPM, word count, fixes, timestamps)
- Insights dashboard shows usage stats, streak calendar, app breakdown, and voice metrics
- Offline still works — Groq unavailable → regex fallback, app never crashes or blocks

---

## Architecture

M2 adds three independent subsystems on top of the M1 core:

```
M1 core (unchanged except DictationEngine wiring):
  AudioCaptureService → TranscriptionService → [CleanupSubsystem] → InsertionService

New in M2:
  CleanupSubsystem:   TieredCleanupService → GroqCleanupService (primary)
                                           → RegexCleanupService (fallback)

  Insights backend:   DictationEngine → InsightsRepository → SQLite

  Insights UI:        MainWindow (nav shell)
                        └── InsightsView (UserControl)
                        └── SettingsView (UserControl, API key input)
```

**New NuGet packages:**
- `Microsoft.Data.Sqlite` (8.x) — local SQLite storage
- No new packages for Groq — uses built-in `HttpClient` + `System.Text.Json`

## Subsystem 1: Groq Cleanup

### Interface

```csharp
// Services/ICleanupService.cs
public interface ICleanupService
{
    Task<CleanupResult> CleanAsync(string rawText, string? appContext = null);
}

// Models/CleanupResult.cs
public record CleanupResult(string Text, int FixesCount, string Tier);
```

`FixesCount` = `Math.Abs(rawWordCount - cleanedWordCount)` — net word delta, good enough for "fixes made" metric.

### RegexCleanupService

Rename existing `CleanupService` → `RegexCleanupService`, implement `ICleanupService`. The `Clean(string)` method becomes the body of `CleanAsync`. Tier = `"regex"`.

```csharp
// Services/RegexCleanupService.cs
public class RegexCleanupService : ICleanupService
{
    public Task<CleanupResult> CleanAsync(string rawText, string? appContext = null)
    {
        var cleaned = Clean(rawText);
        int fixes = Math.Abs(CountWords(rawText) - CountWords(cleaned));
        return Task.FromResult(new CleanupResult(cleaned, fixes, "regex"));
    }
    // existing Clean(), RemoveSelfCorrections(), RemoveFillers(), etc. unchanged
}
```

### GroqCleanupService

```csharp
// Services/GroqCleanupService.cs
public class GroqCleanupService : ICleanupService
{
    private readonly HttpClient _http;
    private readonly SettingsService _settings;

    public bool IsAvailable => !string.IsNullOrWhiteSpace(_settings.Current.GroqApiKey);

    public async Task<CleanupResult> CleanAsync(string rawText, string? appContext = null)
    {
        // POST https://api.groq.com/openai/v1/chat/completions
        // Authorization: Bearer {GroqApiKey}
        // Model: settings.GroqModel
        // System prompt: see below
        // User message: rawText
        // max_tokens: 1024, temperature: 0
        // Timeout: 5 seconds (CancellationTokenSource)
        // Returns: choices[0].message.content (the cleaned text)
    }
}
```

**System prompt (verbatim):**
```
You are a dictation cleanup assistant. Given raw speech-to-text output, return only the cleaned text — no explanation, no preamble.

Rules:
1. Remove filler words: um, uh, er, you know, sort of, kind of, basically, literally.
2. Resolve self-corrections: if the speaker says "no wait", "actually no", "scratch that", "never mind", "forget that", "let me rephrase", or "or rather", discard everything before that phrase and keep what comes after.
3. Fix capitalisation: first word of each sentence capitalised, proper nouns.
4. Add punctuation where natural pauses suggest it.
5. Fix grammar and word order lightly — preserve the speaker's voice.
6. Do not add words, summarise, or change meaning.
```

**Request body shape:**
```json
{
  "model": "llama-3.3-70b-versatile",
  "messages": [
    { "role": "system", "content": "<system prompt above>" },
    { "role": "user", "content": "<rawText>" }
  ],
  "temperature": 0,
  "max_tokens": 1024
}
```

**Response parsing:** `response.choices[0].message.content` (standard OpenAI format — Groq is compatible).

**Timeout:** 5-second `CancellationTokenSource`. On `TaskCanceledException` or any `HttpRequestException`, throw — caller (TieredCleanupService) handles fallback.

### TieredCleanupService

```csharp
// Services/TieredCleanupService.cs
public class TieredCleanupService : ICleanupService
{
    private readonly GroqCleanupService _groq;
    private readonly RegexCleanupService _regex;

    public async Task<CleanupResult> CleanAsync(string rawText, string? appContext = null)
    {
        if (_groq.IsAvailable)
        {
            try { return await _groq.CleanAsync(rawText, appContext); }
            catch { /* fall through to regex */ }
        }
        return await _regex.CleanAsync(rawText, appContext);
    }
}
```

## Subsystem 2: SQLite Insights Backend

### Database location

`%AppData%\WhisperFlowLocal\insights.db`

Created on first run by `InsightsRepository.InitAsync()`.

### Schema

```sql
CREATE TABLE IF NOT EXISTS dictations (
    id            INTEGER PRIMARY KEY AUTOINCREMENT,
    timestamp     TEXT    NOT NULL,   -- ISO 8601 UTC
    app_name      TEXT    NOT NULL,   -- process name, e.g. "slack"
    app_title     TEXT    NOT NULL,   -- window title
    duration_ms   INTEGER NOT NULL,   -- recording length in ms
    word_count    INTEGER NOT NULL,   -- words in cleaned text
    wpm           REAL    NOT NULL,   -- word_count / duration_ms * 60000
    raw_text      TEXT    NOT NULL,   -- Whisper output before cleanup
    cleaned_text  TEXT    NOT NULL,   -- after cleanup
    cleanup_tier  TEXT    NOT NULL,   -- "groq" or "regex"
    fixes_count   INTEGER NOT NULL,   -- net word delta
    insertion_ok  INTEGER NOT NULL    -- 1 = success, 0 = failed
);
```

### InsightsRepository

```csharp
// Services/InsightsRepository.cs
public class InsightsRepository
{
    public Task InitAsync();                                        // CREATE TABLE IF NOT EXISTS
    public Task RecordAsync(DictationRecord record);               // INSERT
    public Task<int> GetTotalWordsAsync();                         // SUM(word_count) WHERE insertion_ok=1
    public Task<double> GetTodayWpmAsync();                        // AVG(wpm) WHERE date=today
    public Task<int> GetTotalFixesAsync();                         // SUM(fixes_count)
    public Task<List<AppUsageItem>> GetAppBreakdownAsync();        // GROUP BY app_name, COUNT(*)
    public Task<List<StreakDayItem>> GetStreakDataAsync(int days);  // per-day counts, last N days
    public Task<VoiceStats> GetVoiceStatsAsync();                  // avg duration, avg confidence, wpm variance
}
```

**Supporting records:**

```csharp
public record AppUsageItem(string AppName, int Count, double Percent);
public record StreakDayItem(DateTime Date, int Count);
public record VoiceStats(double AvgDurationSec, double AvgConfidencePct, double WpmVariance, double GroqUsagePct);
```

`WpmVariance` — computed in C# from the raw WPM list (standard deviation). SQLite doesn't have `STDDEV`, so fetch all WPM values and compute in-memory.

### TranscriptionResult (extend TranscriptionService)

Add a return type that includes Whisper segment confidence:

```csharp
// Models/TranscriptionResult.cs
public record TranscriptionResult(string Text, double AvgConfidence);
```

`TranscriptionService.TranscribeAsync` returns `TranscriptionResult` instead of `string`. `AvgConfidence` = average of `segment.Probability` across all segments (Whisper.net exposes this on `SegmentData`).

### DictationEngine changes

```csharp
// DictationEngine.cs — updated EndRecordingAsync
private string _currentAppName = string.Empty;
private string _currentAppTitle = string.Empty;
private readonly Stopwatch _recordingTimer = new();
private readonly InsightsRepository _insights;

// In StartRecording():
_currentAppName = _focus.GetForegroundAppName();
_currentAppTitle = _focus.GetForegroundWindowTitle();
_recordingTimer.Restart();

// In EndRecordingAsync():
var durationMs = (int)_recordingTimer.ElapsedMilliseconds;
var transcriptionResult = await _transcription.TranscribeAsync(pcm);
var cleanupResult = await _cleanup.CleanAsync(transcriptionResult.Text, _currentAppName);
State = RecordingState.Inserting;
bool ok = _insertion.Insert(cleanupResult.Text);
if (!ok) throw new InvalidOperationException("SendInput returned 0");
await _insights.RecordAsync(new DictationRecord(
    DateTime.UtcNow, _currentAppName, _currentAppTitle,
    durationMs, CountWords(cleanupResult.Text),
    CountWords(cleanupResult.Text) / (durationMs / 60000.0),
    transcriptionResult.Text, cleanupResult.Text,
    cleanupResult.Tier, cleanupResult.FixesCount, ok));
State = RecordingState.Idle;
```

`CountWords(string s)` = `s.Split(' ', StringSplitOptions.RemoveEmptyEntries).Length`
